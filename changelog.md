# Changelog проекта fintrack

## [1.0.0] - 2026-06-07

### Изменения
- При регистрации пароль хэшируется с помощью bcrypt
- Эндпоинт all : теперь работает с пагинацией и возвращает либо по 10 записей, либо за последний год, в зависимости от задачи
- Эндпоинт category-month : Выборка по категории за последний год, если выбран месяц - то за текущий месяц.
Вместо extract для более быстрого поиска использованы index на поле created_at и фильтрация по этому полю.
- Фронтенд на HTML/JS
- get_user и get_db вынесены в core/dependencies

## Главное ##
Теперь fintrack - полноценный сайт, в котором можно отслеживать свои финансы и получить краткую статистику по месяцу/категории 
в виде графиков.

## Разделы: ##
- **Логин и регистрация** : стандартные формы
- **Главная** : Статистика за текущий месяц по доходам/расходам продемонстрирована donut- диаграммой. Суммарные доходы и расходы, Топ 3 категории по обоим типам.
- **За год**: Статистика за год представлена в виде столбчатых диаграмм (сумма/категория)
- **Фильтры** : возможность отфильтровать финансы по месяцу, типу и категории.
- **Записи** : фильтрация и удаление записи
- **Добавить**: Добавить доход/расход по категории

### Новые технологии
- bcrypt, index (PostgreSQL)
